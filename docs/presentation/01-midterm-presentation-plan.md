> **작성자** Kim minkyoung · **작성일** 2026-06-10
>
> **용도** 중간 발표(20분+)의 설계도. 슬라이드별 핵심 메시지·담을 내용·발표용 출처·멘트 힌트를 정의한다. 이후 슬라이드 제작은 이 문서를 따른다.

## 발표 개요

| 항목 | 내용 |
|---|---|
| 발표 시간 | 20분 이상 (본문 약 22분 + Q&A) |
| 슬라이드 | 27장 (0~5부) |
| 청중 | 멘토·동료 수강생 |
| 범위 | 사용자 리서치 → 시장 검증 → 솔루션 기획 → 시스템 설계(의사결정 관점) |
| 제외(최종 발표로) | 파이프라인 구현 상세, LLM 품질 평가, 데모, 인프라·비용 최적화 |

### 발표 전체 내러티브 (한 문장)

> **"투자 시장은 1,410만 명으로 폭발했는데, 정작 그 시장을 *읽어주는 일*은 비싸거나 가짜였다. AI가 그 독해 노동을 처음으로 저가·안전하게 만든다 — 그게 장독대다."**

이 한 문장이 발표 전체의 척추다. 1부(문제)→2부(검증)→3부(솔루션)→4부(설계)가 모두 이 문장으로 회귀하도록 구성한다.

### 출처 표기 원칙

- 슬라이드의 모든 수치에는 **원 출처**(기관·언론·자체 설문)를 각주로 표기한다. 전체 일람은 [부록 A. 인용 수치 카드](#부록-a-인용-수치-카드) 참조.
- 자체 설문은 항상 **"자체 설문(N=50, 2026.06.04~10 최종, 편의표본)"**으로 표기하고, 발표에서도 "탐색적 조사"임을 명시한다.
- 내부 추정치(AI 대체 가치, TAM/SAM/SOM 일부 필터)는 **"자체 추정"** + 가정을 함께 표기한다.

## 슬라이드 구성안

### 0부. 인트로 (2장, 약 1분)

#### S01. 표지
- **핵심 메시지**: 장독대 — "시장 독해를 대신 해드립니다"
- **담을 내용**: 서비스명·태그라인, 팀/발표자, "중간 발표: 사용자 리서치와 서비스 설계"
- **멘트 힌트**: "장독대는 '**장**독(시**장** 독해)을 **대**신 해드립니다'의 줄임말입니다. 이름 풀이로 가볍게 시작.

#### S02. 발표 흐름 + 범위 선언
- **핵심 메시지**: 오늘은 "왜 만들고, 무엇을, 어떤 구조로"까지. "어떻게 구현했나"는 최종 발표에서.
- **담을 내용**: 5부 목차 + 한 줄 내러티브 문장 제시. "기술 검증·구현·데모 → 최종 발표" 박스로 명시.
- **멘트 힌트**: 범위를 먼저 선언하면 "구현은 어디 있나"라는 중간 질문을 차단할 수 있다.

### 1부. 문제 발견 — 시장과 사용자 (7장, 약 7분) ⭐ 발표의 무게중심

#### S03. 시장 배경 — 폭발한 투자 인구
- **핵심 메시지**: 1,410만 명이 주식에 뛰어들었고, 2030 투자자의 70%는 경력 1년 미만이다.
- **담을 내용**: 개인투자자 1,410만 명(2024) · 2030 투자자 약 70%가 경력 1년 미만 · 평균 투자금 100만원 이하 37%, 100~500만원 31%
- **출처(슬라이드 표기)**: 한국예탁결제원(경향신문 보도, 2025) / 서울경제 / 토스증권 자체조사(팍스넷뉴스)
- **멘트 힌트**: "국민 4명 중 1명이 투자자입니다. 그런데 이들 대부분은 *준비 없이* 들어왔습니다."

#### S04. 문제의 심각성 — 못 읽어서 잃고, 가짜에 돈을 쓴다
- **핵심 메시지**: 신규 투자자 60%가 손실을 보고, 검증 안 된 리딩방에 2년간 1.3조 원이 흘러갔다.
- **담을 내용**: 신규 투자자 약 60% 손실 경험 · 리딩방 사기 피해 2년간 1.3조 원(1만 4,629건) · 20대 데이트레이딩 비중 80.8% · 2030 빚투(신용거래) 약 46조 원
- **출처**: 자본시장연구원 / 농민신문(2025) / 시사저널
- **멘트 힌트**: "수요는 이미 1.3조 원 규모로 *화폐화*되어 있습니다. 문제는 그 공급이 전부 불량이라는 겁니다." — 이 수치는 뒤(2부 시장 검증)에서 다시 쓰인다고 예고.

#### S05. 직접 물어봤다 — 자체 설문 결과
- **핵심 메시지**: 사용자가 입으로 말하는 어려움 1위는 손실 공포(34%), 2위는 시작점 부재(28%).
- **담을 내용**: 설문 개요(온라인, 14문항, N=50 최종, 2030이 전부 — 30대 52%·20대 48%) · Pain 자기보고 순위: 손실 공포 34% > 시작점 모름 28% > 신뢰 불가 18% = 시간 없음 18% > **독해 불가 2%(최하위)**
- **출처**: 자체 설문(N=50, 2026.06.04~10 최종, 편의표본 — 탐색적 조사)
- **멘트 힌트**: "그런데 이상한 게 하나 있습니다. '뉴스를 봐도 모르겠다'는 응답이 *최하위*였습니다. 정말 독해가 문제가 아닌 걸까요?" — 다음 슬라이드로 가는 긴장 조성.

#### S06. 반전 — 말하는 Pain과 진짜 Pain은 다르다
- **핵심 메시지**: 직접 호소는 2%뿐이지만, 실측하면 공시를 읽을 수 있는 사람은 22%에 불과하다. **독해력 진입장벽이 근본 원인이다.**
- **담을 내용**: 독해 난이도 계층 실측 — 헤드라인 80% → 기사 본문 68% → **리포트 46% → 공시(DART) 22% → 재무제표 24%** ("L2→L3 사이에서 끊긴다") · 용어의 이중 구조: 기초 용어(ETF 86%·배당 96%·손절 94%)는 통과, **컨센서스만 56%** · 정보원: 유튜브 54%·뉴스레터 54% vs 공시 직접 8% · 자기인식 역설: 78%가 "나는 주린이"라면서 용어 평균 정답률 83%
- **출처**: 자체 설문(N=50)
- **멘트 힌트**: "사용자는 자신이 못 읽는다는 걸 *모릅니다*. 그래서 증상(손실·혼란)만 호소합니다. 표면 호소로 후킹하되, 독해를 해법으로 제시하는 게 저희 메시지 전략입니다." — 멘토가 강조한 "독해력이 진입장벽" 축이 실측으로 확인됐음을 언급.

#### S07. 6대 Pain 지도와 악순환 고리
- **핵심 메시지**: 6개 Pain은 목록이 아니라 하나의 순환이고, 첫 단추는 P1(독해)이다.
- **담을 내용**: 6대 Pain 표(P1 독해 / P2 손실 공포 / P3 시작점 / P4 신뢰 불가 / P5 위축 / P6 시간 부족 — 각 한 줄 정의·근거 수치) · 악순환 다이어그램: 독해 불가 → 시작점 혼란 → 검증 안 된 정보 의존 → 손실 → 불안·위축 → 다시 단타·빚투 · "데였지만 떠나지 않는다": 20대 중단율 29.6%·재투자 의향 77.6% 동시 최고
- **출처**: 자체 설문(N=50) / 자본시장연구원 / 농민신문 / 트렌드모니터
- **멘트 힌트**: "P1을 끊으면 P3·P4·P2가 연쇄적으로 풀립니다. 그래서 저희 제품의 1순위는 독해입니다."

#### S08. 페르소나 — 우리가 만난 6명
- **핵심 메시지**: Primary는 김주린 — 경력 8개월, 투자금 300만 원, 첫 3개월 -15%, 공시는 안 읽는 28세 직장인.
- **담을 내용**: 김주린 카드 상세(진입 계기 FOMO → 손실 → 불안, Goal: "내 종목 뉴스를 쉬운 말로, 맥락과 출처와 함께") · 보조 5인 한 줄 요약(이코린·박관망·정워킹·한회복·최늦깎이) · 설문 분류 결과로 김주린형 집중 확인(연령·자기인식 부합)
- **출처**: 자체 페르소나 설계(데스크 리서치 + 자체 설문 보정)
- **멘트 힌트**: 보조 페르소나는 "확장 경로의 복선"이라고만 언급하고 2부 시장 규모에서 회수.

#### S09. 유저 저니 — 3대 결정적 순간
- **핵심 메시지**: 김주린은 ①신뢰("또 리딩방 아냐?") → ③첫 독해("이건 진짜 이해된다") → ⑤습관화(아침 브리핑)의 3개 관문을 넘어야 한다.
- **담을 내용**: 김주린 감정 곡선(인지😟 → 가입😐 → 첫 독해🙂 → 학습🙂 → 재방문😀 → 확산😀) · 최저점 = 인지 단계의 신뢰 의심 · 전환점 = 첫 독해의 가치 체감 · 각 관문에서 필요한 것(신뢰 시그널 / 맞춤 해설 / 개인화 브리핑)
- **출처**: 자체 유저 저니 설계
- **멘트 힌트**: "이 3개 관문이 3부에서 보여드릴 기능 우선순위와 1:1로 대응됩니다." — 3부 복선.

### 2부. 시장 검증 — 벤치마킹·포지셔닝 (4장, 약 4분)

#### S10. 경쟁 서비스 비교 — 같은 사용자, 네 가지 처방
- **핵심 메시지**: 토스·어피티·핀트·로빈후드 모두 주린이를 노리지만, 아무도 "읽는 법"을 가르치지 않는다.
- **담을 내용**: 4사 비교표 — 토스증권(누적 660만·MAU 384만, 거래 중심, 수익 80%대가 위탁매매수수료) / 어피티(구독 80만+, "무시 안 하는 톤", 단 종합 경제로 주식은 일부) / 핀트(회원 135만·AUM 5,200억, AI 일임 — **학습이 안 남음**) / 로빈후드(첫 증권계좌 비중 50%+, 진입장벽 제거 — 단 무방비 유입으로 게임화 규제 $750만 합의)
- **출처**: Businesskorea(2024.12) / 어피티 회사소개 / 스포츠경향(2026.4) / 미국 SEC S-1·Boston Globe(2024)
- **멘트 힌트**: 로빈후드 반면교사를 한 문장으로 — "쉬운 설명과 안전한 설명은 다릅니다. 진입장벽만 낮추면 준비 안 된 사용자가 다칩니다."

#### S11. 5가지 빈틈과 포지셔닝
- **핵심 메시지**: "핀트가 떠먹여준다면, 장독대는 읽는 법을 가르쳐 스스로 판단하게 한다."
- **담을 내용**: 경쟁사가 못 채우는 5가지 빈틈 — ①개인화 큐레이션 ②주식 특화 심화 ③단계적 학습 커리큘럼 ④정확한 쉬움(리스크·맥락 동반 단순화) ⑤독해력이 남는 구조 · 포지셔닝 문장 크게: "어피티의 친절함으로 번역하되, 주식에 특화해 개인화·심화한다"
- **출처**: 자체 벤치마킹 분석(4사 공개 자료 기반)
- **멘트 힌트**: "대신해줌(delegation) vs 이해시켜줌(comprehension)"의 분기를 칠판 그리듯 설명. 핀트는 경쟁자가 아니라 *정반대 처방*이라는 프레임.

#### S12. 포지셔닝, 실측으로 검증했다
- **핵심 메시지**: "어떤 방식을 선호하나?"라고 물었더니 독해 대행이 64%로 압승했다.
- **담을 내용**: 선호 방식 분포 — **독해 대행 64%** > 일임 14% > 알림 12% > 강의 4% · 서비스 수요 긍정 90%(쓰겠다 62% + 생각해보겠다 28%)
- **출처**: 자체 설문(N=50, 선호 방식 단일선택 문항)
- **멘트 힌트**: 이 한 장이 2부의 클라이맥스. "가설이 아니라 실측입니다. '이해시켜줌' 포지셔닝이 일임·알림·강의를 모두 이겼습니다. 중간 집계 61.5%에서 최종 64%로, 표본이 늘수록 더 또렷해졌습니다."

#### S13. 시장 규모와 비즈니스 — 핵심만
- **핵심 메시지**: TAM 1.17조 → SAM 2,450억 → SOM 약 7.6억. 그리고 이 시장은 AI라서 비로소 열렸다.
- **담을 내용**: TAM/SAM/SOM 깔때기(개인투자자 1,410만 = 연 1.17조 → 2030 주린이 약 300만 = 연 2,450억 → 3년차 유료 1.4만 명 = 연 약 7.6억, ARPU 월 4,500원 최종 설문 실측 보정) · AI 대체 가치: 사람이 1:1 독해 시 월 50만 원/사용자(자체 추정) vs AI 월 1~2천 원 → **99.6% 절감, "비싸서 존재할 수 없던 시장"의 대중화** · 수익모델 한 줄: 구독 + 광고 + B2B(지불의사 무료 60% 실측 → 초기엔 광고·B2B 병행) · 확장 경로: 김주린(SOM) → 박관망·한회복(SAM) → 중장년·B2B(TAM)
- **출처**: 한국예탁결제원(경향신문 보도) / 서울경제 / 자체 설문(N=50, 지불의사) / 자체 추정(인건비·전환율 가정 명시)
- **멘트 힌트**: "절대 금액보다 *좁히는 논리와 확장 순서*가 결론입니다. 그리고 ARPU는 계획가 6,900원이 아니라 설문 실측(유료 의향자 평균 상한 약 4,500원)으로 *하향 보정*했습니다" — 스스로 보수적으로 교정했음을 어필. BMC·5 Forces·BCG는 "별도 문서로 분석 완료, 질문 주시면 답변" 한 줄로만.

### 3부. 솔루션 기획 (5장, 약 4분)

#### S14. 가치 제안 — Pain마다 기능이 있다
- **핵심 메시지**: "출처 달린 쉬운 말로 → 스스로 판단하게" — 6대 Pain 전부에 대응 기능을 설계했다.
- **담을 내용**: Pain→기능 매핑 표 — P1 독해 → **개인화 독해 엔진**(P0) / P4 신뢰 → **출처·검증 시그널**(P0) / P5 위축 → 무시 안 하는 톤·질문형 용어풀이(P1) / P6 시간 → 하루 5분 아침 브리핑(P1) / P3 시작점 → 왕초보 트랙·커리큘럼(P1~P2) / P2 손실 → 리스크 동반 해설·손실 복기(P2)
- **출처**: 자체 기획(Pain 지도 기반 우선순위)
- **멘트 힌트**: "기능 욕심이 아니라 우선순위입니다. 기능적 Pain(P1·P4)을 먼저 풀면 감정·시간 Pain이 연쇄 완화되므로 P0는 딱 두 개입니다."

#### S15. 핵심 경험 — Issue Docent
- **핵심 메시지**: 매일 핵심 이슈를 골라, 같은 구조로 풀어준다: 무슨 일이에요 → 왜 중요한가요 → 오해 방지 → 앞으로 뭘 보면 될까요.
- **담을 내용**: Issue Docent 4단 구조 목업(1️⃣핵심 사실 → 2️⃣맥락·관점 → ★주린이의 흔한 오해 차단 → 3️⃣체크포인트) + 연결 모듈(섹터·종목 부채살 — "추천이 아니라 길 안내") · 예시 1건을 실제 뉴스로 채워서 보여주기
- **출처**: 자체 콘텐츠 설계
- **멘트 힌트**: 추상 설명보다 예시 한 건이 강하다. "삼성전자 감산" 같은 익숙한 뉴스로 4단 구조를 채워 시연하듯 읽기.

#### S16. 학습 경험 — 읽고 끝나지 않는다
- **핵심 메시지**: 핀트와의 결정적 차이 — 장독대는 쓸수록 독해력이 사용자에게 남는다.
- **담을 내용**: 학습 루프 — 클릭형 용어 풀이(기초가 아닌 **심화 용어** 중심, 컨센서스 56% 근거) → 전문가의 시각(해석 + 본문 근거 하이라이트) → 이해도 퀴즈 3문항 → 다음 이슈 추천 4건(관련 2·관심 1·다양성 1)
- **출처**: 자체 설문(N=50, 심화 용어 정답률) / 자체 콘텐츠 설계
- **멘트 힌트**: "사용자가 보는 주린이 졸업 기준은 '스스로 종목 분석 가능'(70%)이었습니다. 저희 학습 루프의 종착점이 정확히 그것입니다."

#### S17. 신뢰 설계 — 리딩방과 무엇이 다른가
- **핵심 메시지**: 신뢰는 톤이 아니라 구조로 만든다 — 출처 명시, 투자 권유 금지, 저작권 안전.
- **담을 내용**: ①모든 해설에 1차 정보 출처 링크 ②표현 규칙: "유망하다·수혜주·급등 예상" 금지 / "가능성이 언급되고 있다·영향을 받을 수 있다" 허용 — 투자 권유가 아닌 학습 서비스 정체성 ③저작권 설계: 뉴스는 제목+URL만 저장, 본문은 분석 시점에만 처리 후 폐기
- **출처**: 자체 콘텐츠 정책 설계
- **멘트 힌트**: "첫 화면에서 사용자가 '또 리딩방 아냐?'라고 의심한다는 걸 저니에서 확인했습니다(1부 S09). 이 세 가지가 그 신뢰 게이트의 답입니다."

#### S18. 저니와 기능의 정합 — 설계가 리서치로 회귀한다
- **핵심 메시지**: 3대 결정적 순간마다 정확히 하나의 P0/P1 기능이 서 있다.
- **담을 내용**: 매핑 다이어그램 — ①신뢰 게이트 ↔ 출처·검증 시그널(P0) / ③첫 독해 가치 체감 ↔ Issue Docent 맞춤 해설(P0) / ⑤습관화 ↔ 개인화 아침 브리핑(P1) · 초기 핵심 지표(OMTM) = 리텐션(D7/D30): "이해됨"이 습관이 되는지가 가장 강한 신호
- **출처**: 자체 설계(유저 저니 × 기능 우선순위)
- **멘트 힌트**: 1부 S09에서 깔아둔 복선 회수. "리서치 따로 기능 따로가 아니라는 것"이 3부의 결론.

### 4부. 시스템 설계 — 사용자 가치 관점 (6장, 약 4.5분)

> 이 부는 "무엇을 만들었나"가 아니라 **"왜 이렇게 설계했나"**의 의사결정 서사로만 푼다. 코드·스키마·파라미터는 보여주지 않는다.

#### S19. 전체 파이프라인 — 매일 아침이 만들어지는 길
- **핵심 메시지**: 수집 → 전처리 → 임베딩·클러스터링 → 엔티티 추출 → 분석 → Issue Docent 생성.
- **담을 내용**: 6단계 파이프라인 한 장 다이어그램 + 각 단계가 만드는 사용자 가치 한 줄씩(수집="재료" / 클러스터링="오늘의 이슈 발견" / 분석·생성="주린이의 언어로")
- **출처**: 자체 시스템 설계
- **멘트 힌트**: "지금부터 4장은 이 길 위에서 내린 의사결정 세 가지를 보여드립니다." — 4부를 '의사결정 투어'로 프레이밍.

#### S20. 설계 철학 — 두 개의 두뇌
- **핵심 메시지**: "다음 단계로 갈 흐름을 LLM이 판단하는가?" — 이 질문 하나로 Airflow와 LangGraph의 경계를 그었다.
- **담을 내용**: 2계층 오케스트레이션 — 정형 단계(수집~클러스터링)는 Airflow(스케줄·재시도·이력), 추론·동적 분기(분석~생성)는 LangGraph(슈퍼바이저-워커) · "LLM을 호출해도 입출력이 고정이면 일반 Task"라는 판별 기준
- **출처**: 자체 아키텍처 설계(멘토 피드백 반영)
- **멘트 힌트**: "처음엔 'LLM 쓰면 LangGraph'라고 생각했지만, 멘토링에서 기준을 다시 세웠습니다" — 피드백으로 설계가 바뀐 사례임을 명시(5부 복선).

#### S21. 의사결정 ① — 뉴스는 많을수록 좋은가? (수집)
- **핵심 메시지**: 아니다. 고정 RSS 16개로 좁혔다 — 주린이에게 필요한 건 양이 아니라 안정적 품질이다.
- **담을 내용**: 키워드 검색 API 대신 증권 전문 고정 피드 16개(국내 13 + 해외 3, 일 약 310건) · 효과: 품질 예측 가능성 + 외부 API 의존 제거 + 임베딩 비용 절감 · 저작권 안전(제목+URL만 저장)과 한 몸의 결정
- **출처**: 자체 수집 설계
- **멘트 힌트**: "사용자 리서치의 결론('내게 필요한 뉴스를 이해하고 싶다')이 수집기 설계까지 내려온 사례입니다."

#### S22. 의사결정 ② — 오늘의 이슈가 몇 개인지 미리 알 수 없다 (클러스터링)
- **핵심 메시지**: 그래서 클러스터 수를 미리 정하는 K-means가 아니라 HDBSCAN을 골랐고, 단독 보도도 버리지 않는다.
- **담을 내용**: 자동 클러스터 수 결정(오늘 이슈가 3개일 수도 20개일 수도) · singleton = 노이즈가 아니라 잠재적 고가치 이슈 · 복합 중요도 스코어(볼륨 0.4 + 속도 0.3 + 감성 0.15 + 기업 중요도 0.15)로 "오늘 주목할 뉴스" 선정 — 가중치는 초기 휴리스틱, 실데이터로 교정 예정
- **출처**: 자체 설계(업계 벤치마크: 뉴스 볼륨·속도 기반 중요도 산정 사례 참고)
- **멘트 힌트**: 수식 깊이로 들어가지 말 것. "도메인의 불확실성(이슈 개수를 모름)이 알고리즘 선택을 결정했다"는 서사만.

#### S23. 의사결정 ③ — 같은 뉴스도 맥락이 있어야 읽힌다 (RAG)
- **핵심 메시지**: 공시·재무·사업보고서를 미리 쌓아두고, 뉴스 해설 시점에 기업 컨텍스트를 주입한다.
- **담을 내용**: 예시로 설명 — "삼성전자 반도체 감산 발표" + RAG(반도체 매출 비중·이익 추세) → "이미 적자인 사업의 비용 절감이자 공급 조정"으로 해석 → 단순 호재/악재 이분법 탈피 · 적재 vs on-demand 기준: "시계열 추세 분석을 반복하는가?"(공시·재무 적재 / 주가·환율은 조회만)
- **출처**: 자체 데이터 설계(공시·재무: DART 공개 데이터 활용)
- **멘트 힌트**: 이 장의 주인공은 기술이 아니라 "오해 방지"(S15의 ★)가 어떻게 가능해지는가다.

#### S24. 데이터로 결정한다 — 임베딩 모델 평가 (맛보기)
- **핵심 메시지**: 모델 선택도 감이 아니라 3축 평가로 — 그리고 "금융 특화"는 함정이었다.
- **담을 내용**: 3축 평가 설계(비지도 클러스터링 / 정답 라벨 일치 / RAG 검색 recall) → gemini-embedding-001 확정 · 교훈 한 줄: 금융 특화 모델이 검색에서 오히려 크게 뒤처짐 — "특화 라벨보다 직접 평가" · "평가 상세와 수치는 최종 발표에서" 예고
- **출처**: 자체 평가 실험(2026.06)
- **멘트 힌트**: 4부의 마침표이자 최종 발표 예고편. 30초만 쓰고 넘어갈 것 — 깊이 들어가면 "기술 발표"가 되어버린다.

## 부록 B. 예상 Q&A

1. **"ChatGPT한테 물어보면 되지 않나? (대체재 위협)"**
   → 인정하되 반박: 범용 AI는 ①내 종목 맞춤 큐레이션이 없고 ②출처 검증이 약하며 ③학습 커리큘럼·복습이 없다. 산업 구조 분석(5 Forces)에서도 대체재를 최대 위협으로 식별했고, 대응은 "개인화+검증된 출처+학습"의 묶음으로 전환비용을 만드는 것. 실측에서도 사용자가 원한 건 "알아서 답해주는 것"이 아니라 매일 골라서·쉽게·출처와 함께(64%)였다.

2. **"N=50으로 뭘 주장할 수 있나?"**
   → 선제 방어: 편의표본임을 슬라이드에 명시했고, 절대수치가 아니라 **가설의 반증 여부**로만 사용("용어를 절반도 모른다"는 가설은 기각하고 보정, 독해 계층 가설은 확인). 핵심 결론(독해 대행 선호 1위, 독해 계층 구조, Pain 순위)은 중간 집계(N=39)와 최종(N=50)에서 동일하게 유지돼 방향의 안정성은 확인됨. 통계적 일반화는 베타 사용자 행동 데이터로 검증 예정.

3. **"무료가 60%인데 사업이 되나?"**
   → 그래서 SOM ARPU를 계획가 6,900원에서 실측 4,500원으로 스스로 하향 보정했고, 초기 수익화는 구독이 아니라 광고·B2B(어피티 검증 모델) 병행이 현실적이라고 결론. 한편 유료 의향은 중간 33%→최종 40%로 오히려 상승. 초기 핵심 지표도 매출이 아닌 리텐션(D7/D30).

4. **"토스가 이 기능을 붙이면 끝 아닌가? (진입 위협)"**
   → 토스의 엔진은 거래 수수료(수익 80%대)라 "거래를 줄이더라도 이해시키는" 제품과 이해 상충. 우리는 사용자의 이해도·생존율을 KPI로 삼는 학습 제품으로 포지션이 다르며, 데이터·학습 이력 lock-in과 B2B 제휴(화이트라벨)가 방어 전략.

5. **"투자 권유 서비스랑 뭐가 다른가? (규제)"**
   → 표현 규칙으로 구조적 차단("수혜주·급등 예상" 금지), 모든 해설에 출처, 종목 추천이 아닌 "길 안내"(부채살 연결). 학습 서비스 정체성을 콘텐츠 규칙 레벨에서 강제한다.

6. **"기술은 언제 보여주나?"**
   → 최종 발표에서 파이프라인 전체 구현 + LLM 품질 평가 + 실제 뉴스 기반 Issue Docent 데모. 오늘 4부는 그 설계의 "왜"까지만.
